# ADR-0009 — Asimilación progresiva de skills

Estado: propuesta para validar.

## Contexto

Una skill puede contener reglas, recursos,
scripts y comportamientos implícitos.

## Decisión propuesta

Permitir importación encapsulada,
estructuración progresiva y activación
por capacidad validada.

## Motivos

Reducir el coste de adopción.

No inventar decisiones que no aparecen
en la fuente original.

## Consecuencias

La asimilación debe generar un informe
de fidelidad y conservar el material original.

La importación no ejecuta código de terceros.

## Revisit trigger

Revisar cuando el primer conjunto de skills
de prueba muestre pérdida de comportamiento
en la conversión.
