# SkillGraph

Plataforma local-first para convertir skills de agentes en workflows
declarativos, verificables y extensibles.

> Estado: **bootstrap**. Roadmap y especificación en `external/blueprint-v1/`.

## Instalación rápida

```bash
mise install                # Python 3.13 + uv
mise run sync               # venv local con dev deps (uv sync --group dev)
mise run cli                # smoke test de la CLI
```

## Estado de la iniciativa

- Plan de ejecución: `CURRENT.md`
- Estado estructurado: `STATE.yaml`
- Diario: `SESSION-JOURNAL.md`
